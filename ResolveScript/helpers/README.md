# Image helper (optional)

Place the PyInstaller-built `convert_photos_helper-*` executable here when
Resolve's Python does not include Pillow.

Build from the repo root:

- Windows: `PythonInterface/build_convert_photos_helper.ps1`
- macOS/Linux: `PythonInterface/build_convert_photos_helper.sh`

Copy the artifact from `PythonInterface/dist/` into this folder.
